# Каталог мер социальной поддержки

Электронная библиотека Хабаровского центра социальной поддержки населения. В ней хранят документы, раскладывают их по папкам, ищут по тексту и разграничивают доступ по ролям.

## Запуск

```bash
cp .env.dev .env
docker compose up -d --build
```

Приложение открывается на `http://localhost:12000` (порт задаётся `APP_PORT`). Логин и пароль берутся из `.env`; в шаблоне это `admin` / `admin`. Перед реальным запуском смените `SECRET_KEY`, `ADMIN_PASSWORD` и `POSTGRES_PASSWORD`.

При первом старте применяются миграции, создаётся администратор и базовые роли.

## Что входит в стек

| Сервис | Назначение |
| --- | --- |
| `app` | Сайт, API и вход в систему |
| `db` | PostgreSQL 16 |
| `redis` | Очереди задач |
| `solr` | Полнотекстовый поиск |
| `gotenberg` | Конвертация офисных файлов в PDF |
| `index_worker` | Индексация документов |
| `backup` | Регулярные копии базы |

Часовой пояс контейнеров — `Asia/Vladivostok`. Файлы документов лежат в каталоге `media/`, он не хранится в git.
